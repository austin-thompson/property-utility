# Cycle 2 — Rough Outline

## Working intent

Cycle 2 will build on the geographic foundation and the first metrics slice by turning the system toward more reusable analytical concepts and broader product-facing workflows.

## Likely focus areas

- refine the first comparison and similarity concepts into a more durable metric model
- define a small set of domain-level metrics that can be reused across analysis flows
- connect metrics to the existing geographic-context records in a lightweight and testable way
- begin shaping the first API experience for analysis results rather than raw records

## Open questions

- should the first metric be expressed as a domain object, an API payload, or both?
- should comparison metrics remain purely derived from address and geography, or should they later incorporate richer signals?
- how much of the first analysis experience should be exposed in this cycle versus deferred to later work?

## Suggested milestone

The first milestone for Cycle 2 should be a small, verifiable metrics slice that makes the system feel more analytical without overcommitting to a full scoring framework.
